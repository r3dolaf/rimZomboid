# H6b Guardar y cargar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Guardar la partida en el navegador (sola y a mano), «Continuar» en la portada, y exportar
e importar un archivo.

**Architecture:** `src/sim/save.ts` (de mundo a texto y de texto a mundo, con versión y la caja
común una sola vez); `src/ui/saveStore.ts` (el navegador y los archivos); el panel «Partida» y la
portada; `main.ts` arranca con un mundo nuevo o cargado.

**Tech Stack:** TypeScript, Phaser 4, Vite, Vitest, Playwright.

**Spec:** docs/superpowers/specs/2026-11-04-h6b-guardar-design.md

## Global Constraints

- `src/sim` puro; el navegador, solo en `src/ui`.
- Textos en `es.ts`.

## Review Focus

1. Referencias compartidas que el JSON duplicaría (la caja común; algo más).
2. Cargar una partida acabada o en mitad de un viaje.
3. El navegador sin almacenamiento (modo privado) o lleno.
4. Un archivo que no es una partida.
5. Guardar sola cada mañana sin repetir ni saltarse días a velocidad ×3.

## Tareas

### Task 1: De mundo a texto y de texto a mundo

- `saveGame(base, meta): string`, `loadGame(text): { world, meta } | { error }`, `SAVE_VERSION`.
- Tests en `src/sim/save.test.ts`: misma partida y mismo futuro; con sitios y viajes; versión
  distinta; archivo roto.

### Task 2: El navegador y los archivos

- `src/ui/saveStore.ts`: guardar, leer, borrar (con fallos controlados); exportar (descarga) e
  importar (leer un archivo).
- Tests en `src/ui/saveUi.test.ts`.

### Task 3: Pantalla

- Botón y panel «Partida»; guardar sola cada mañana; avisos.
- Portada con «Continuar (día N)» e «Importar partida».
- `main.ts`: arrancar con un mundo cargado.
- Tests.

### Task 4: Navegador y documentación

- `e2e/save.spec.ts`; hoja de ruta.
